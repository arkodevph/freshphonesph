# Database field dictionary

Generated by `apps/api-ts/scripts/document-assistant.ts` from `apps/api-ts/prisma/schema.prisma`. Regenerate after schema changes. This is storage documentation; a model's existence does not grant assistant access. See [Fresh AI API tools](110-fresh-ai-api-tools.md) and its operation allowlist.

Money is decimal PHP, never a float or directly editable balance. Payment dates scope payment reports; installment due dates scope scheduled earnings; task/support reports use creation dates. Client/member balances use lifetime net Finance-verified credit. Scheduled amounts are neither collections nor profit.

Identifiers are server-generated UUIDs unless specified otherwise. `?` means nullable, `[]` means a collection/relation, `@unique`/`@@unique` constrain duplicates, `@updatedAt` is maintained by Prisma, and `version` is used for optimistic concurrency. Relations are references, not permission grants. Financial and audit history uses restricted deletion. Authentication, tokens, identity documents, applicant details and confidential HR are private and are excluded from assistant tools unless an explicitly listed API provides a permitted projection. Never send password hashes, session tokens or provider keys to the model.
