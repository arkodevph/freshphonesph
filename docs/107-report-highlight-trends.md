# Report highlight changes

Add a compact direction arrow and percentage beside the report-card value, following the user's supplied four-card Collections screenshot (`/tmp/codex-clipboard-UqXZH7.png`). That screenshot is the primary composition reference: retain the grid, glass surfaces, labels, value hierarchy, notes and icon positions. No new card layout, chart or dependency is introduced.

## Behavioral goal and flow

The CEO/Owner should recognize how each period-scoped figure changed without calculating or remembering the prior total. Routine flow: apply dates and optional batch/status → read value → read adjacent arrow/percentage → inspect the visible comparison date range if needed. Missing dates, failed prior requests and unavailable historical data must have explicit neutral states. Refresh figures retries the comparison. These are observed implementation requirements; no user performance improvement has been measured.

Route: `user-expi` → `ui-design-index` → `ui-design-systems`. Selected patterns: label/value/compact delta hierarchy, a nearby visible filter/comparison context, and explicit loading/empty/error states. The locked screenshot supplies composition, and the existing system tokens supply surfaces and text. Green/red are restricted to the small directional badge and never tint the card.

## Calculation and permissions

The baseline is the immediately preceding equal-length **inclusive** date range. November 1–6 compares with October 26–31. Preserve the same batch/status filters and use the existing authenticated report-family endpoint. There is one additional read per displayed summary, with cancellation on unmount/filter changes; failed comparisons do not hide current figures. The selected reporting window may include partial days; this is a calendar-period comparison, not an elapsed-time-normalized forecast.

All report-card families share the indicator. No business record or permission changes are made. The two Collections stock metrics have no historic baseline and remain neutral. Task/support status figures compare the current states of records scoped to each created-date period; they are not point-in-time status snapshots. Report snapshot storage and exports are unchanged.
