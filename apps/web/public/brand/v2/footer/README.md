# V2 nature footer background

`nature-ground-v1.webp` is an original landscape generated with the built-in
imagegen tool on 2026-11-02 for Jaycee's nature-footer request. The supplied
reference informs the grassy landscape, water, cloud sky and cheerful digital
art direction. It is a new image, not extracted artwork from that screenshot.

The generated PNG was converted to a 2172 × 724 WebP (112,994 bytes) for the
website; the composition was preserved. The original remains in the local generated-images directory.
The background is decorative and applied only in the V2 Footer CSS Module.
The existing asset-sync command copies it to the standalone landing app.

## Generation prompt

Create an original panoramic landscape illustration to be used ONLY as the background of the Fresh Phones PH website footer. This is an image asset, not a screenshot or website mockup. Wide 3:1 composition. A dreamy cheerful Y2K digital nature scene: rolling soft lime-green and mint grassy hills along the lower left and lower right, a calm sparkling cyan-blue lake curving through the lower center, distant tiny green trees, soft rounded white clouds and a powder-blue sky. Soft 3D rendered forms with a delicate fine halftone/dither print texture, playful early-internet optimism, matching a light-blue cloud-themed brand with pastel pink/lavender accents. Keep the upper HALF predominantly very pale blue open sky with subtle clouds near the far horizon, quiet uncluttered negative space for navy footer text overlaid later by HTML. Ground and water are concentrated in the bottom third, sweeping meadow edges frame the scene. Gentle daylight, polished dimensional landscape, lovely atmospheric depth and small sparse glints in the distant grass/water. Landscape must fill edge to edge with no frame. No text, letters, logos, phones, UI, people, animals, floating spheres or buildings. Do not generate any webpage or footer content. Make the foreground nature clearly recognizable yet soft enough to support readable text above.
