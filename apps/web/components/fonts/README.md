the complete upstream license is preserved in `OFL.txt`.

- Project: https://github.com/sursly/sono
- Distribution: https://github.com/google/fonts/tree/main/ofl/sono
- Source file: https://raw.githubusercontent.com/google/fonts/main/ofl/sono/Sono%5BMONO%2Cwght%5D.ttf
- Retrieved: 2026-11-02.
- Source SHA256: `247ca641ca7066e3addc8081d89613c06a79e4276cd4f2164d07a6493530010f`.
- `sono-variable.woff2` is the complete source font compressed with FontTools,
  without glyph removal or outline changes. 67,168 bytes.
- Axes: weight 200–800; `MONO` 0–1. V2 explicitly uses `MONO: 1`.

Self-hosted through `next/font/local`; no third-party font request at runtime.
The upstream font does not include the Philippine peso sign U+20B1. The scoped
font stack retains the existing local Nunito font and system fallback for
missing glyphs. Do not replace the peso character or format money differently.

Jaycee requested Diatype Rounded Mono, then explicitly selected a free
rounded-mono alternative when its commercial webfont files were unavailable.
Sono is the chosen alternative, not the proprietary font. Sometype Mono was
also reviewed; Sono's soft forms and full 200–800 weight range fit the reference
and existing page weights more closely.
